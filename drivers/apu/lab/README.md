# Original APU lab archive

This folder preserves the scripts and notes used during the original driver experiments. **It is a historical record, not a general installer.** Some scripts change drivers, boot settings, or recovery tasks using paths and device names specific to the test Deck.

For current user instructions, use [download and preparation](../docs/installation.md). For repeatable package builds, use the [build guide](../docs/build.md).

## Reading the archive

- [README.txt](README.txt): the original lab overview and setup notes.
- [NORMAL-MODE-BOOT.txt](NORMAL-MODE-BOOT.txt): the tested restart-based selection procedure, including its machine-specific requirements.
- [GUARDED-RELOAD.txt](GUARDED-RELOAD.txt): the original live-reload trial and recovery guard.
- [ERROR-INVESTIGATION.txt](ERROR-INVESTIGATION.txt): the earlier failed-reload and resume investigation.
- [SIGNING-RESEARCH.txt](SIGNING-RESEARCH.txt): device revision and Windows signing research.

The original notes have been left intact so they still describe the experiment that actually happened. An old OEM INF number or recovery path is evidence from that machine, not a value to reuse on yours. No archived watchdog is running merely because you downloaded these files.
